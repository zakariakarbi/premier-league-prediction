# Premier League Match Prediction

## Overview
A machine learning project that analyzes historical Premier League matches and predicts match outcomes.

## Dataset
Historical match data stored in `premier-league-matches.csv`.

## Methodology
- Data cleaning and preprocessing
- Exploratory data analysis
- Feature engineering
- Machine learning model training and evaluation

## Technologies
- Python
- Jupyter Notebook
- Pandas
- Scikit-learn
- Matplotlib

## How to Run
1. Install Python.
2. Install the required libraries.
3. Open `PLpredction.ipynb` in Jupyter Notebook or VS Code.
4. Run the notebook cells in order.

## Disclaimer
Predictions are estimates and do not guarantee actual match results.
